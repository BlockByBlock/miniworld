# Forgotten Crypt

`Forgotten Crypt` is a small, standalone Three.js vertical slice built as a
ten-minute preview. It uses a focused selection of the CC0 character and
dungeon assets recorded in World of ClaudeCraft's asset register, but does not
copy the game's runtime, branding, UI, or server.

## Run locally

```sh
npm install
npm run dev
```

Open the local Vite URL, then use `WASD` to move, click or `Space` to strike,
and `E` to open the chest or escape through the gate.

## Build

```sh
npm run build
```

See [ASSET_CREDITS.md](./ASSET_CREDITS.md) for the exact source commit and
license record for the bundled models.
